 MultiTaskLearningFramework 是一个支持多任务学习（MTL）的开源机器学习框架，能够同时训练多个任务，并在共享网络层的基础上优化它们。通过实验验证多任务学习（MTL）相较于单任务学习（STL）的优势，并展示它如何提高多个任务的表现。
